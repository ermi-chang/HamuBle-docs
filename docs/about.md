# 关于 HamuBle

HamuBle 是一个用于《碧蓝幻想》（GBF）**救援多人**房间的
过滤与显示 Chrome 扩展。它在浏览器侧边栏中整理显示救援房间列表，
并提供 HP、参战人数、排序等过滤功能，帮助你更快找到想要参加的房间。

::: tip 在阅读本页之前
请先看一下 [使用前的小提醒](/license)。本扩展为非官方工具，
**希望你尽量不要把本扩展放进直播 / 视频里**。
:::

## 主要特性

- **救援列表过滤**：按 HP、参战人数、FP 对象等条件筛选救援房间。
- **排序**：提供多种排序方式，便于浏览。
- **隐藏已参战**：可把已参战的房间从救援列表中隐藏。
- **过滤模板**：保存常用的过滤组合，一键切换。
- **侧边栏显示**：在浏览器侧边栏中整理显示，浏览更轻松。
- **我的任务**：记录自己开启过的任务，方便再次开启，并可隐藏已完成的任务。
- **掉落监视**：在战斗结算画面识别掉落，按日期累计到掉落日历。
- **仪表盘**：汇总今日自发次数、活动公告与掉落日历。
- **收藏**：10 个网址书签位，一键回到常用页面。

## 设计原则

本扩展坚持**只读**设计：

- 仅**读取**游戏页面信息进行整理显示，**不会自动操作游戏**。
- **不会代替你点击、不会自动战斗、不会自动加入房间。**
- 页面跳转等操作均通过浏览器标准方式进行。

请始终把它当作一个“信息浏览与整理”工具，而非自动化工具来使用。

## 运行环境

- Google Chrome 116 及以上版本
- 仅在《碧蓝幻想》网页版页面上运行
